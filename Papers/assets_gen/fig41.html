OFFAT-X End-to-End Methodology Pipeline Flowchart
01
Scope & Target Allowlist Validation
Parses offat-x.yml; validates host boundaries & rate limits to prevent unauthorized scanning.
02
Specification Ingestion & Normalization
Normalizes OpenAPI 2.0 & 3.x; maps endpoints, HTTP verbs, parameters, schemas & auth tiers.
▼
03
Sandboxed Reconnaissance (DIRB)
Spawns hardened, isolated ephemeral container to fuzz and identify undocumented Shadow APIs.
04
Dependency Graph & Chain Planner
Builds DAG G=(V,E) of producer-consumer links; solves BFS state setup sequence bounded to L ≤ 4.
▼
05
Multi-Tier Role-Differential Execution
Runs chained state setup as Owner; replays target endpoint across Guest, Low, Premium, Admin tiers.
06
Semantic Response Diffing Engine
Evaluates Jaccard schema (J), value overlap (O), and error penalty (E). Calculates score D against threshold τ = 0.70.
▼
07
CVSS v3.1 Scoring & Remediation Synthesis
Calculates CVSS base score; assigns OWASP Top 10 category & generates targeted source code patches.
08
SARIF Reporting & CI/CD Security Gate
Emits SARIF 2.1.0 & HTML report; executes GitHub Action gating merge on new Critical/High findings.
